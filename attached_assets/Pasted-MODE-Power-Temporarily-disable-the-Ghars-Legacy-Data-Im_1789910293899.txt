MODE: Power

Temporarily disable the Ghars Legacy Data Import feature behind a PLATFORM-ADMIN controlled feature flag.

IMPORTANT:
Do NOT delete, rollback, or simplify any of the completed Legacy Import implementation.

Preserve all existing importer code, tests, database structures, mappings, historical finance support, batch rollback, OCR, XLSX/PDF/image support, and review UI.

The feature is simply NOT READY FOR CUSTOMER USE YET.

GOAL:

Platform Super Admin can enable or disable Legacy Data Import globally.

For now the Production/default state must be:

DISABLED

When disabled:
- customers can see that the feature exists
- they cannot use it
- show "Coming Soon"
- direct URLs must be blocked
- backend import APIs must also be blocked
