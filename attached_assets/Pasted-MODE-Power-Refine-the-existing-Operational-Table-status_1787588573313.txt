MODE: Power

Refine the existing Operational Table status column into a unified patient clinical summary.

The current table already shows implant statuses, but now the system also supports adjunct surgical procedures such as:

- زراعة عظم
- رفع الجيب الفكي
- إبعاد / نقل العصب السنخي السفلي

A patient may have these procedures WITH or WITHOUT implants.

Therefore the current implant-only status column is no longer sufficient.

==================================================
1. RENAME THE COLUMN
==================================================

Rename the existing column:

"حالة الزرعات"

to:

"ملخص الحالة"

This column should answer, at a glance:

"What is the patient's current implant/procedure situation?"

Do NOT add another table column.

The Operational Table is already dense.

Use ONE compact summary column.

==================================================

The column must be DERIVED only from canonical clinical records.

Use:

`implants.status`

B. Adjunct surgical procedures:

- زراعة عظم
- رفع الجيب الفكي
- إبعاد / نقل العصب السنخي السفلي

Do NOT use:

- manually stored patient summary text
- a new patient-level status field
- frontend-only stored status
- duplicated dashboard state

Do NOT create a new database field for "ملخص الحالة".

This is a derived presentation only.

==================================================

Before implementation, inspect the current Operational Report API response.

Confirm whether it already exposes:

- active implant statuses
