PHASE 1 SCOPE — READ ONLY
==================================================

The first implementation must be READ-ONLY.

The AI must NOT:

- create records,
- edit patients,
- edit cases,
- add implants,
- record payments,
- create follow-ups,
- archive/delete records,
- send WhatsApp,
- change settings.

It may only:

- search,
- retrieve,
- calculate using existing trusted business logic,
- summarize,
- explain existing records,
- navigate the user to existing records.

Write actions may be considered later as a separate phase with explicit confirmation.

SECURE TOOL ARCHITECTURE
==================================================

The language model must NEVER receive unrestricted database access.

Do not allow free-form SQL generation/execution.

Design a server-side tool layer.

Possible tools include:

- searchPatients
- getPatientOverview
- getPatientImplants
- getPatientCases
- getPatientFinancialSummary
- getPatientFollowups
- getPatientTimeline
- getUpcomingAppointment
- getOverdueFollowups
- getReadyForProstheticCases
- getOperationalStatistics
- getCollectionsSummary
- getImplantSystemStatistics

Reuse existing API queries/business logic wherever possible.

Do not duplicate financial calculations or clinical status logic.

Every tool call must:

1. authenticate the current application user,
2. enforce existing server-side permissions,
3. validate parameters,
4. query only the minimum required data,
5. return structured JSON,
6. avoid exposing secrets or unrelated patient data.

==================================================
FINANCIAL PERMISSIONS
==================================================

Financial answers must obey the current permission model.

Example:

If a user without financial-view permission asks:

"كم باقي على المريض؟"

the backend must NOT send the financial value to the AI.

Return an authorization result instead.

Do not rely on prompting the AI to hide unauthorized information.

Enforce it in backend tools.
