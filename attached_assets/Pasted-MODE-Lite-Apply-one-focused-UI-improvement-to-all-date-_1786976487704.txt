## GOAL

Users should select dates and times from UI controls instead of manually typing date/time strings.

## DATE PICKER

Replace manually editable date fields with a proper calendar/date picker.

- open a calendar picker,
- allow selecting the date visually,
- display the selected date in clear Arabic-friendly format,
- keep the stored value in the existing ISO/database format.

The user should not need to manually type:

dd/mm/yyyy
mm/dd/yyyy
yyyy-mm-dd

Use the existing UI/design system where possible.

Prefer the existing shadcn/Popover/Calendar components if already available.

Do not add a heavy date library unless absolutely necessary.

Use a clear selectable time control.

or a clean time dropdown.

Example:
