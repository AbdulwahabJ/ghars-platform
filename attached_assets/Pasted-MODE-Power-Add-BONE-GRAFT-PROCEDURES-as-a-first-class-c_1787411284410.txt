==================================================
2. CLINICAL MODEL
==================================================

Bone grafting is a PROCEDURE belonging primarily to an implant case.

It must be possible to have:

Patient
→ Implant Case
→ 0 implants
→ 1 or more bone graft procedures

A graft may optionally relate to:
- an FDI tooth/site
- an implant

but neither is mandatory unless clinically required by the specific record.

Recommended canonical entity:

`bone_graft_procedures`

Minimum fields:

- id
- implant_case_id
- implant_id nullable
- procedure_date
- site / FDI region nullable
- graft_type
- graft_material / source nullable
- membrane_used boolean
- membrane_type nullable
- quantity_or_size nullable
- treating_doctor / clinician using the project's existing clinician convention
- status
- notes nullable
- created_at
- updated_at
- archived_at or existing archival convention

Use appropriate date/date-time types consistent with the project.

Do not use hard delete if the rest of the clinical system uses archive.
