English LTR

3. CENTERING MUST BE DIRECTION-INDEPENDENT
==================================================

Use direction-independent viewport centering.

Recommended concept:

position: fixed
left: 50%
top: 50%
transform: translate(-50%, -50%)

OR an equivalent robust fixed overlay layout such as:

fixed
inset-0
display grid/flex
place-items-center / items-center justify-center

Choose the implementation that best fits the existing Radix/shadcn architecture.

CRITICAL:

Do NOT allow RTL styles to invert:

translateX
left
right

for modal positioning.

==================================================

rtl:right-*
ltr:left-*
right-[50%]
left-[50%]
translate-x rules altered by direction
margin-based modal positioning
logical start/end rules applied to the modal container

Remove/fix anything that makes the dialog location depend on document direction.
