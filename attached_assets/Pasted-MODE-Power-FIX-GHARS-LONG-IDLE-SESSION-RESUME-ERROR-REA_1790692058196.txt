MODE: Power

FIX GHARS LONG-IDLE / SESSION-RESUME ERROR.

REAL PRODUCTION ISSUE:

If Ghars remains open in a browser tab for several hours, sometimes around half a day, the application eventually shows the global error fallback and the user must manually refresh the browser.

This occurs while the application was previously working normally.

IMPORTANT CONTEXT:

Current production session configuration was previously verified as:

- PostgreSQL connect-pg-simple
- rolling session
- approximately 12-hour session lifetime
- secure/httpOnly cookie in Production

The reported failure timing is suspiciously close to the session lifetime.

DO NOT simply increase the session to an unlimited duration.
DO NOT hide the problem with window.location.reload().
DO NOT redesign the application.
DO NOT publish.

Find and fix the actual idle/resume lifecycle.

==================================================
