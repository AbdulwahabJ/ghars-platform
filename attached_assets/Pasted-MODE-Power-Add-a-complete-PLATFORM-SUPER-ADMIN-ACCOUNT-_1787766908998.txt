5. USERNAME CHANGE SECURITY
==================================================

Changing the Platform Admin username is security-sensitive.

Require:

Current Password

before saving a new username.

Do not accept username change using only an authenticated browser session.

After successful username change:

- audit it
- preserve the current session safely OR require re-login if that matches the existing session security architecture
- ensure next login uses the NEW username
- old username must stop authenticating

Do not expose whether unrelated customer usernames exist beyond the safe validation response.
