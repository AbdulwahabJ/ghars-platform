## 1. USE A VERTICAL ALPHA MASK

Apply a CSS alpha mask directly to the portrait image.

Preferred approach:

`mask-image`
and
`-webkit-mask-image`

using a vertical linear gradient.

Suggested starting point:

* 0% → 55%: fully opaque
* around 60%: begin subtle fade
* around 75%: partially transparent
* around 90–95%: almost transparent
* 100%: fully transparent

Example direction:

linear-gradient(
to bottom,
#000 0%,
#000 55%,
rgba(0,0,0,0.95) 62%,
rgba(0,0,0,0.65) 75%,
rgba(0,0,0,0.25) 88%,
transparent 100%
)

Tune the actual stops visually.

Do NOT blindly copy these percentages if the real portrait needs slightly different values.

The final result must look natural.
