==================================================

6. PASSWORDS MUST NEVER BE VIEWABLE
==================================================

CRITICAL:

No administrator may ever VIEW or retrieve an existing password.

This applies to:

- Platform Super Admin
- Tenant Admin
- support staff

Never implement:

- Show current password
- Reveal password
- Decrypt password
- Display password hash

Passwords remain one-way hashed using the application's existing secure password-hashing implementation.

Administrators may only RESET a password to a NEW value.
