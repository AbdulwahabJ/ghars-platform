MODE: Power

Build a SMART UNIVERSAL LEGACY DATA IMPORT system for Ghars.

PRIMARY GOAL:
Doctors/clinics must NOT be required to fill a Ghars-specific Excel template.

They should be able to upload their EXISTING legacy files as they already have them, even when column names/order/layout differ between clinics.

Supported sources should eventually include:

- XLSX
- CSV
- PDF tables
- scanned/image tables (PNG/JPG)

The system should intelligently understand the source structure, map it into Ghars canonical entities, validate everything, and show a safe preview BEFORE writing anything.

IMPORTANT:
Accuracy and data safety are more important than automation.

AI/OCR may help understand data,
but AI/OCR must NEVER directly write clinical or financial records into the database without deterministic validation + human approval.

Do NOT publish.
Do NOT import real Production data yet.

==================================================
1. SIMPLE USER EXPERIENCE
==================================================

The user experience must remain very simple:

STEP 1:
Upload existing file

STEP 2:
Ghars analyzes it automatically

STEP 3:
Review only warnings / uncertain mappings

STEP 4:
Confirm import

Do NOT force users to manually rebuild their spreadsheets.

==================================================
14. TREATMENT AND FINANCE MUST BE SEPARATE
==================================================

Critical rule:

Clinical completion and financial completion are separate.

Possible states:

Treatment complete + Paid in full

Treatment complete + Remaining balance

Treatment ongoing + Paid in full

Treatment ongoing + Remaining balance

Never derive one from the other.
