23. WHATSAPP WORKFLOW
==================================================

Do not use WhatsApp Business API.

Use a standard WhatsApp deep link.

The workflow must work with:

- WhatsApp mobile application,
- WhatsApp desktop application where supported,
- WhatsApp Web.

Workflow:

1. User clicks إرسال واتساب.
2. Display the reason for communication.
3. Suggest a matching approved template.
4. Display a message preview.
5. Allow the user to edit the message.
6. Validate the mobile number.
7. Open WhatsApp with the number and encoded message.
8. Return to the application.
9. Ask the user to record the communication result.

The application must not claim that it knows:

- whether the message was actually sent,
- delivered,
- read,
- or replied to.

It only knows:

- the WhatsApp link was opened,
- and the result manually recorded by the user.

Saudi number normalization:

If number begins with:

05XXXXXXXX

Convert to:

9665XXXXXXXX

If number begins with:

+966

Remove only the plus sign for the WhatsApp URL.

Support other international numbers without incorrectly forcing them into Saudi format.

Show an error if the number is missing or clearly invalid.

Communication result options:

- تم فتح واتساب
- تم التواصل
- لا يوجد رد
- أكد الموعد
- طلب تغيير الموعد
- سيتم التواصل لاحقًا
- رقم غير صحيح
